# Security policy

This plugin runs inside online shops and talks to a service that registers invoices with the
Spanish Tax Agency. Please report security problems privately.

## How to report

Use GitHub's private vulnerability reporting: the **Security** tab of this repository →
**Report a vulnerability**. Do **not** open a public issue, discussion or pull request for a
security problem.

Include the plugin version, WordPress, WooCommerce and PHP versions, a description and, if
possible, steps to reproduce. Never send real API keys, certificates or customer data.

## What to expect

- An acknowledgement within **72 hours**.
- An assessment and a plan within 7 days.
- A fix released, and the advisory published, within **90 days** of the report at the latest
  (coordinated disclosure). We credit reporters unless they prefer otherwise.

## Supported versions

Only the latest release receives security fixes.
